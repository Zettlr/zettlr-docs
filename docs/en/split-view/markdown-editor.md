# Markdown Editor

When you open a Markdown document in the split view, this will display a [Markdown editor](../editor/index.md). The Markdown editor allows you to edit files with complex workflows. Since Zettlr is a Markdown editing app, it is the most powerful component of the app. Instead of telling you more here, you can read more on the features and capabilities of this editor [in its dedicated documentation section](../editor/index.md).
