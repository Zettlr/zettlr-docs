# Block Extensions

In this section, we document additional block elements that Zettlr understands. Some of these elements may not be universally supported, so we will add information on where you can expect these elements to work or not.

## Footnotes

One of the most fundamental extensions to Markdown that many people will require is the ability to add footnotes. Zettlr supports these natively.

Zettlr makes working with footnotes straight forward, and you can read more in the [dedicated section](./footnotes.md).

## Math

Zettlr also supports math blocks. Math comes in two flavors: Inline-math and block math. You mark these elements with dollar-signs.
