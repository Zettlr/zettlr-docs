# Atalhos de teclado

Esta página contém uma lista de todos os atalhos disponíveis no aplicativo.

**Observação:**

	A tecla <kbd>Cmd/Ctrl</kbd> deve ser interpretada da seguinte forma: se você estiver no macOS, pressione a tecla <kbd>Cmd</kbd>. Em qualquer outra plataforma, pressione <kbd>Ctrl</kbd>.

Esses atalhos estão disponíveis em todo o aplicativo.

|----------------------------------------------------------------|-------------------------|
| <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd> | Abrir preferências |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>,</kbd> | Abrir gerenciador de ativos |

| <kbd>Cmd/Ctrl</kbd>+<kbd>O</kbd> | Abrir novo espaço de trabalho |
| <kbd>Cmd/Ctrl</kbd>+<kbd>S</kbd> | Salvar arquivo |
| <kbd>Cmd/Ctrl</kbd>+<kbd>E</kbd> | Exportar |
| <kbd>Cmd/Ctrl</kbd>+<kbd>P</kbd> | Imprimir |

## Atalhos de preenchimento automático e correção automática

Esses atalhos funcionam quando um prompt de preenchimento automático está aberto e durante o preenchimento automático.

| Atalho | Descrição |
|----------------------------------------------------------------|------------------------------------------------------------------------------------|
| <kbd>Escape</kbd> | Fechar o painel de preenchimento automático |
| <kbd>↑</kbd>, <kbd>↓</kbd> | Selecionar sugestão seguinte/anterior |
| <kbd>PageUp</kbd>, <kbd>PageDown</kbd> | Mover a sugestão selecionada por página |
| <kbd>Enter</kbd>, <kbd>Tab</kbd> | Aceitar conclusão |
| <kbd>Backspace</kbd> | Se houver uma aspa inteligente antes do cursor, substitua-a por uma aspa normal |
| <kbd>Space</kbd>, <kbd>Enter</kbd> | Substituir automaticamente se o texto à frente do cursor corresponder a um padrão de substituição |
