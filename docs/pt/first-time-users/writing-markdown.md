# Escrevendo Markdown

Agora que você configurou seus espaços de trabalho e criou um arquivo, a próxima etapa é simplesmente começar a escrever.

Zettlr usa Markdown. Mais especificamente, ele usa um superconjunto de vários padrões chamado “Pandoc Markdown”.

Mesmo que você nunca tenha trabalhado conscientemente com Markdown, certamente já o utilizou, pois ele é onipresente. Observe o seguinte texto:

```markdown
# What is Markdown?

Markdown is a **markup language** that can be used to *format* (but not
style!) text documents. It supports every common and some useful syntactic
elements including [links](https://www.zettlr.com), `monospaced text`,
or even more complex elements like blockquotes and lists:

> This is a quotation.

1. List item One
2. A second item
3. Third time's a charm
```

Como você notará, este texto é fácil de ler – mesmo em sua forma “bruta” – e fácil de escrever. É por isso que muitos softwares que você usa todos os dias oferecem suporte a isso. Por exemplo, você pode usar Markdown em…

*…Discordar mensagens
*…WhatsApp
*…muitos fóruns
*… GitHub
*…Folga
*… e muito mais.

Para começar rapidamente a usar a sintaxe do Markdown, recomendamos fortemente o guia de [Aprenda X em Y Minutos](https://learnxinyminutes.com/markdown/). O guia está disponível em vários idiomas e tudo o que você vê lá é compatível com Zettlr. Se você quiser se acostumar a escrever Markdown limpo e inequívoco, [veja as especificações do CommonMark](https://spec.commonmark.org/current/). Além disso, há um [livro sobre a sintaxe Markdown com sabor do GitHub](https://gitbookio.gitbooks.io/markdown/content/).  Para aqueles envolvidos na escrita acadêmica, vale a pena ler a [seção do manual Pandoc sobre seu Markdown estendido](https://pandoc.org/MANUAL.html#pandocs-markdown).

## Atalhos comuns para formatação de texto

Na maioria das vezes, você não precisa digitar todos os caracteres de formatação para deixar o texto, claro, em preto. Zettlr incorpora muitos atalhos de teclado comuns para elementos, e alguns tornam o processo ainda mais simples!

Aqui está uma lista de alguns atalhos comuns e como eles funcionam no Zettlr:

| Atalho | Descrição |
|----------------------------------------------------------------|------------------------------------------|
| <kbd>Cmd/Ctrl</kbd>+<kbd>B</kbd> | Ousado |
| <kbd>Cmd/Ctrl</kbd>+<kbd>I</kbd> | Itálico |
| <kbd>Cmd/Ctrl</kbd>+<kbd>K</kbd> | Inserir link.                  |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Inserir imagem |
| <kbd>Cmd/Ctrl</kbd>+<kbd>T</kbd> | Criar lista de tarefas |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Comentário alternativo |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> | Copiar com formatação |
| <kbd>Cmd/Ctrl</kbd>+<kbd>V</kbd> | Colar com formatação |
| <kbd>Cmd/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | Colar como simples |

Existem muitos outros atalhos disponíveis. Você pode encontrar tudo na [página de referência correspondente](../reference/keyboard-shortcuts.md).

**Observação:**

Quando digitamos <kbd>Cmd/Ctrl</kbd>, queremos dizer "pressione a tecla Command se estiver usando um Mac, e a tecla Control, se estiver usando um computador Windows ou Linux".
