# Escolhendo quais arquivos exibir

Por padrão, o gerenciador de arquivos exibe apenas um pequeno conjunto de todos os arquivos dentro de seus espaços de trabalho: arquivos Markdown, arquivos de texto simples, arquivos de dados JSON e YAML e arquivos LaTeX.

No entanto, dependendo do que funciona para você, você também pode fazer com que o Zettlr exiba uma ampla variedade de tipos de arquivos adicionais. Por exemplo, você pode ter que trabalhar muito com imagens. Fazer com que eles apliquem no gerenciador de arquivos pode ser uma maneira rápida de ver quais imagens você tem dentro de suas pastas e abri-las a partir daí.

Para configurar quais arquivos o Zettlr exibe em seu gerenciador de arquivos, você pode consultar a configuração “Tratamento de arquivos” na seção “Avançado” das opções.

![preferences_file_treatment.png](../img/preferences_file_treatment.png)

A configuração do tratamento de arquivo é dividida em duas partículas. Primeiro, uma enumeração tabular de alguns tipos de arquivos comuns e, segundo, um campo que permite definir extensões arbitrárias de nomes de arquivos. Quaisquer extensões de nome de arquivo definido nessa segunda configuração estarão disponíveis apenas na barra lateral.

## Configurando tipos de arquivos comuns

Tipos de arquivo “comuns” são tipos de arquivo comuns para usuários do Zettlr. Isso inclui, em primeiro lugar, Markdown integrado e arquivos de código. Estes são os arquivos mencionados acima, e sempre serão mostrados no gerenciador de arquivos e sempre abertos com o Zettlr.

As outras classes de tipos de arquivos comuns são imagens e documentos PDF, documentos do Office (incluindo arquivos Word e LibreOffice, apresentações e arquivos Excel) e arquivos de dados (arquivos CSV, arquivos de estado ou arquivos RData).

Você pode escolher se esses arquivos serão exibidos no gerenciador de arquivos (primeira coluna) ou na barra lateral (segunda coluna). Para imagens e arquivos PDF, você também pode optar por abri-los diretamente no Zettlr usando os visualizadores de imagens e PDF.
