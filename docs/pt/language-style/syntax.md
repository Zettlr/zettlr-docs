# Sintaxe de redução

Além de verificar seu idioma, também é uma boa ideia verificar o estilo da sintaxe do Markdown. Isso garante que seus documentos Markdown permaneçam legíveis, mesmo que alguém tenha apenas um editor de texto simples disponível para ler seus documentos.

## Habilitando o selecionado de estilo Markdown

Para ativar o selecionador de estilo Markdown, vá para a seção Preferências → “Editor”. Ative a configuração “Verificar Markdown para problemas de estilo”. Quando estiver ativo, o Zettlr verifica seus documentos.

Zettlr vem com um conjunto pequeno e opinativo de regras que o selecionado irá testar. Se seus documentos se desviarem desse estilo, o intervalo afetado será marcado.

O selecionador de estilo Markdown utiliza o mesmo mecanismo de verificação ortográfica e das integrações do LanguageTool, para que você possa passar o mouse sobre um problema para ver uma explicação.

Ao contrário de outras ferramentas, o estilo Markdown geralmente envolve blocos inteiros de texto. Portanto, ele utiliza sua própria calha para exibir pequenos sinais de alerta sempre que encontra um problema.

**Observação:**

    A seleção de estilo é opinativa. Acreditamos que as regras que garantem que seus documentos estejam bem formatados. No entanto, o estilo pode ser subjetivo. É por isso que a ferramenta nunca usará linhas vermelhas para marcar problemas. Além disso, você pode desativar a ferramenta caso discorde dela.

**Dica:**

Os problemas de estilo são encontrados junto com quaisquer erros ortográficos e anotações do LanguageTool no controle de diagnóstico na barra de status.
