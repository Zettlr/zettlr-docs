# Uma barra lateral

A barra lateral é um elemento sensível ao contexto que exibe informações e metadados relevantes para o seu arquivo atual. Você pode abri-lo usando o ícone da barra lateral na barra de ferramentas ou pressionando <kbd>Cmd/Ctrl</kbd>+<kbd>0</kbd>.

**Observação:**

Zettlr tem – circunferencial – duas barras laterais: A barra lateral à esquerda é chamada de [Gerenciador de Arquivos](../file-manager/index.md), enquanto a barra lateral à direita – esta barra lateral – é chamada de “a” barra lateral.

A barra lateral contém quatro guias com metadados. São eles (da esquerda para a direita):

* [Índice](./table-of-contents.md): Exiba todos os frascos do documento como uma lista navegável
* [Referências](./bibliography.md): Exiba todos os itens de referência citados em uma bibliografia
* [Arquivos relacionados](./related-files.md): exibe ambientes relacionados a todos os seus arquivos de trabalho
* [Outros arquivos](./other-files.md): Exibe outros (não Markdown) dos diretórios atuais e de ativos.

## Outros arquivos

A última seção contém arquivos que residem no diretório atualmente selecionado, mas não são considerados Markdown nem um dos arquivos de código suportados. Podem ser imagens, arquivos PDF, planilhas do Excel ou qualquer outro tipo de arquivo que você gostaria de ver lá.

![A barra lateral com a quarta aba aberta, outros arquivos](../img/sidebar_other_files.png)

Você pode determinar quais arquivos estão listados aqui adicionando as extensões de arquivo na guia de preferências. Essas extensões de arquivo não diferenciam minuciosamente de minúsculas, portanto, adicionar `.jpeg` mostrará os arquivos `.jpeg`, bem como `.JPEG` e `.JpEg`.

**Dica:**

    Este guia é especialmente útil se você deseja adicionar algumas imagens aos seus arquivos Markdown. Basta arrastá-los e soltá-los no editor e o Zettlra irá envolvê-los em uma tag de imagem.
