# Editor de Markdown

Quando você abre um documento Markdown na visualização dividida, isso criará um editor Markdown. O editor Markdown permite editar arquivos com fluxos de trabalho complexos. Como Zettlr é um aplicativo de edição Markdown, é o componente mais poderoso do aplicativo.

Você pode ler mais sobre os recursos e capacidades deste editor [em sua seção de documentação detipda](../editor/index.md).
