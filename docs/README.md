# Zettlr documentation

Welcome to the official documentation for the Zettlr Markdown editor. This
documentation is available in multiple languages. The **English** translation is
the official documentation, which means that it is the most up to date and most
comprehensive version.

[**Go to the English documentation**](/en/)

Users of Zettlr have translated parts of the documentation into other languages.
These are not always kept up to date at the same speed as the software develops,
but they are sometimes a good alternative for people who wish to read the
documentation in their own language.

To switch the language of the documentation at any time, use the language
selector on top.
